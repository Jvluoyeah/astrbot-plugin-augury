# 占卜插件 (Augury)

简易占卜插件，支持内置随机结果与可选的 LLM 解释。

## 功能

- `/占卜 <事项>` 触发占卜
- 内置 7 档随机结果：大吉、中吉、小吉、吉、末吉、凶、大凶
- 同用户同一天相同占卜内容返回相同结果（按自然天缓存）
- 可选 LLM 解释，支持选择 AI 人格和调整输出字数

## 配置

| 配置项 | 类型 | 说明 |
|--------|------|------|
| 启用大模型解释 | bool | 开启后占卜结果附带 LLM 解释 |
| LLM 解释字数上限 | int | 控制解释最长字符数，默认 50 |
| 占卜人格 | select | 选择 AI 人格风格，留空使用默认人格 |

## 使用示例

```
/占卜 吃饭
```

返回：

```
今天是2026年05月20日
你所求事项: 【吃饭】

结果: 【小吉】
解释: 此事虽有波折但终能如愿，耐心等待即可。
```

## 配置

在 AstrBot WebUI 插件配置中可开启「启用大模型解释」，开启后占卜结果将附带 LLM 生成的一句简短解释。
